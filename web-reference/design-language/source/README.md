# source/

The files the rules in `../` are built from and rendered with. Everything here
is generated by a script in `tools/` or traces to a token in `../tokens.md`;
nothing is drawn by hand.

| Folder | What | Made by |
|---|---|---|
| `brand/` | The mark as vectors: pine, cream and ink | `tools/build_brand.py` |
| `favicon/` | `favicon.svg`, `favicon.ico` (16/32/48), `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `site.webmanifest` | `tools/build_brand.py` |
| `templates/` | One HTML canvas per format, and `base.css`, the site's tokens at canvas scale | by hand, checked by `tools/render.mjs` |
| `renders/` | Every template rendered at size, a copy with safe areas drawn in `guides/`, the A3 PDF, and the brand proof sheet | `tools/render.mjs`, `tools/build_brand.py` |
| `tools/` | The two builders and the tracer they share | — |

## Rebuilding

```bash
python3 -I web-reference/design-language/source/tools/build_brand.py
```

Needs Pillow, numpy and scipy. Traces the shipped mask from
`apps/web/src/assets/evergreen-logo.jpeg`, the same field the site derives in
`apps/web/build.mjs`, and refuses to write if the trace scores under IoU 0.99
against it. Last run 2026-10-15: IoU 0.9927.

```bash
node web-reference/design-language/source/tools/render.mjs
node web-reference/design-language/source/tools/render.mjs --commission
```

Needs Chrome (or `CHROME_PATH`) and a network connection for the fonts. The
first command checks `templates/base.css` against `apps/web/src/styles.css`
and renders nothing if a shared token has drifted. The second plants a drift
and proves that check fails.

Two traps the renderer already handles, recorded so nobody undoes the fix:

- **Its own Chrome profile.** Without `--user-data-dir`, headless Chrome on a
  machine where Chrome is already open hands the job to the running browser,
  exits 0, and writes nothing.
- **An asynchronous spawn.** The templates are served from the same Node
  process, so a synchronous spawn blocks the server Chrome is waiting on.
  Chrome gives up and still exits 0. The script also checks that each file it
  asked for exists, because exit 0 proved nothing both times.

## Verified, 2026-10-15

- **Contrast**, measured on the rendered DOM of all seven templates: no text
  under 4.5:1. The lowest is 4.67:1 (the warning chip's word on its tint).
  Every dark-ground state mark clears 3:1 on its own tint.
- **Faces:** only Newsreader, Inter and Space Mono, all at 400, all loaded.
- **Sizes:** only the six roles at k = 2. At most one element over 80px per
  canvas.
- **Against production**, by computed style: the lockup (24px slot, 9px gap,
  Newsreader 16px −0.005em), the figure slab (label 12px mono at .62, figure
  72px at −0.03em / 1.06, caption 14px at .78, 44ch, 10px gaps, 4px radius) and
  the dashboard's chips (12px mono, `5px 10px`, 7px gap, 9px mark, *archived*
  on the expired chip) — each matched at ×k. The slab was also compared by eye
  at 2× zoom beside `renders/square.png`. The slab's padding is `32px × k`,
  inside the site's `clamp(28px, 4vw, 48px)` range rather than one point in it.
